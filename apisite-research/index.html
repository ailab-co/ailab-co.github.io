一句话：成熟度最高的是海外大平台（OpenRouter、Replicate、fal、AIHubMix、WaveSpeed）；国内中转站里成熟度和设计都过得去的，是 ToAPIs、万川这类“new-api 后端 + 自研前端”的站。它们证明你们不用换后端，重做前端就能达到专业观感。
  1. 个站是 new-api 或 sub2api 模板（原版或只换了首页），控制台都还是模板，已从设计清单剔除。
  2. 国内常用的低价站（FoxRouter、磐石、智元、极速 API 等）价格有竞争力，但成熟度证据少（域名新、无主体、无状态页），大多在 D 级。
  3. Router One 和 AutoRouter 的页面里有面向 AI 代理的隐藏文字（提示注入），我们没有照做，各扣 8 分；Router One 的控制台只作界面参考。
  4. 设计上最值得抄的三点：OpenRouter 的“同模型多渠道表”、fal 的“模型页即 Playground”、AIHubMix 的“模型下线日历和分接口状态页”。
